# Overview
You can run the html file in this directory to look at information about China and its provinces.


## How it works:

1. Click any province/region on the map to open the side panel
2. Click "📖 About this region · 本地介绍" to toggle the reader open/closed
3. collapsible section cards appear: History 历史, Culture 文化, Literature 文学, Culinary 美食, Nature 自然, Economy 经济, Language 语言
4. Click any section header to expand/collapse it (chevron rotates)
5. Language filter chips at the top let you toggle between All / 中文 / Pinyin / English views
6. When you select a different region, the reader auto-updates with that region's content
7. Reader resets when closing the panel

   
## Each section includes:

Mandarin Chinese (zh) — 1-2 sentences
Full pinyin with tone marks (py)
English translation (en)
